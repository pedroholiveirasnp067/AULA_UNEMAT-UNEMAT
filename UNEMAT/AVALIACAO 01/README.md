# Minecraft — Guia para Jogadores

Trabalho da disciplina **Introdução ao Desenvolvimento Web** — Avaliação 01 (HTML5, sem CSS).

## Páginas

| Arquivo | Conteúdo |
|---|---|
| `index.html` | Início e apresentação do jogo |
| `itens.html` | Itens, ferramentas e receitas (com tabelas) |
| `criaturas.html` | Criaturas e biomas (com tabelas) |
| `sobrevivencia.html` | Guia de sobrevivência e formulário para jogadores |

## Estrutura

```
minecraft-guia/
├── index.html
├── itens.html
├── criaturas.html
├── sobrevivencia.html
├── img/      (imagens em PNG)
└── media/    (áudio em WAV)
```
